# Fonts Directory

This folder should contain the following font files:

## Inter Font (for body text)

- Inter-Regular.ttf
- Inter-Medium.ttf
- Inter-SemiBold.ttf
- Inter-Bold.ttf

## Poppins Font (for headings)

- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-SemiBold.ttf
- Poppins-Bold.ttf

Download from: https://fonts.google.com/

Note: The app will still work without local fonts as it uses Google Fonts package which fetches fonts from the network.
